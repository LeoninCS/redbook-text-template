# Risograph Zine

日期：2026-06-02  
随机风格名词：Risograph Zine  
归档模板：`risograph-zine`

## 来源

- Reed College Riso Basics: https://libguides.reed.edu/RISO
- Ms. Registration: https://www.msregistration.studio/risources
- Duplikat Risograph Print Guide: https://www.duplikat.co.uk/riso-print-guide

## 视觉规则

- 2 到 3 个高饱和专色：荧光粉、青蓝、亮黄。
- 米黄色纸底和细颗粒，模拟非涂布纸和油墨纹理。
- 色块使用 multiply 气质的叠印效果。
- 边线轻微错位，保留手工套印偏差。
- 版面气质靠近独立出版物、zine、活动小册子。
