# Quickstart: Redbook Text Template Renderer

## Run Locally

```bash
python3 -m http.server 4173
```

Visit `http://localhost:4173`.

## Validate

```bash
npm test
```

## Manual Checks

1. Confirm the homepage shows at least twenty templates and category filters.
2. Click a template to open the editor.
3. Enter a title, body text, and signature.
4. Confirm the right-side phone preview updates.
5. Switch templates and confirm the text stays.
6. Export PNG and confirm the file downloads.
7. Use PDF export and confirm a print-ready view opens.
8. Check 375px mobile and 1280px desktop widths for clean layout.
